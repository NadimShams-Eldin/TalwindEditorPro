# ديمو التحرير البايتي (Browser Demo)

ديمو متصفح مستقل يوضح الفكرة الأساسية من الخطة: **تحرير HTML بصريًا مع حفظ بايتي، وشرح لكل تعديل**.

## ما يفعله

- يعرض قالب HTML حقيقي (صفحة هبوط عربية RTL) داخل `iframe`.
- يحدد أي عنصر بالنقر، ويقرأ أصناف Tailwind الخاصة به.
- إضافة/إزالة صنف تُعدّل **النص المصدري فقط** في نطاق السمة `class`، دون إعادة تسلسل DOM.
- يعرض `diff` بايتي للتغيير الأخير، وعدد البايتات قبل/بعد، والتراجع خطوة بخطوة.
- يكشف الحالات الثلاث التي تُضلّل المستخدم عادة:
  - **unknown**: صنف لا يولّد CSS.
  - **no effect**: الصنف موجود لكن لا يغيّر أي خاصية محسوبة.
  - **conflict**: صنف مُغطّى بصنف آخر وفق ترتيب الورقة المولّدة.
- المعاينة تستخدم `@tailwindcss/browser@4.3.3` نفسه، أي محرك Tailwind الرسمي.

## التشغيل

```bash
npm install
npm run build
npm run serve
```

ثم افتح `http://127.0.0.1:8000/`.

## الاختبارات

```bash
npm test
```

تغطي المحرر الجراحي: المسارات البنيوية، إضافة/إزالة الأصناف، الحالات الحدّية (سمة بدون اقتباس، سمات مكررة المسافات، أصناف فارغة)، وround-trip بايتي.

## الحدود المعروفة

- لا يوجد حفظ على القرص؛ التعديل يعيش في الذاكرة والتنزيل (`تنزيل الملف`).
- لا يوجد Undo متعدد المستويات إلا داخل الجلسة الحالية.
- كشف التعارض مبني على خصائص CSS الشائعة، لا على محلل كامل لكل utilities.
- `data-tep-path` يُحقن في نسخة المعاينة فقط، ولا يظهر في المصدر ولا في الملف المنزّل.

## العلاقة بالخطة

هذا الديمو يغطي جزءًا من P1 (المحرر الجراحي) وP4 (Class IR المبسط، كشف التعارض، شرح الأثر). النسخة الإنتاجية تستبدل `data-tep-path` بفهرس دائم، وتضيف Ledger كامل وVerify.
